# 工具脚本

> 辅助备考的小工具集。

## 现有脚本

| 脚本 | 状态 | 功能 |
|------|------|------|
| `quiz.sh` | 🚧 占位 | 抽题 / 限时刷题 / 错题本 |
| `stats.sh` | 🚧 占位 | 进度统计 / 错题分析 |
| `mock.sh` | 📋 计划 | 生成模拟卷 |
| `retag.sh` | 📋 计划 | 批量修改 tag |
| `lint.sh` | 📋 计划 | 检查 md front matter 完整性 |

## 实现路线

1. **第一版**（必须）：
   - `quiz.sh`：YAML 解析 + 随机抽题 + 答完统计
   - `stats.sh`：题库数量统计

2. **第二版**（加分）：
   - 错题本（自动记录答错的题）
   - 限时模式（每题 30 秒倒计时）
   - 进度看板自动更新

3. **第三版**（高级）：
   - 联机对战（多人在同一时间做同一套题）
   - 错题曲线（每次错题都记录，对比进步）

## 依赖

- `bash` 4.0+ 或 `zsh` 5.0+
- `yq`（YAML 解析）—— `brew install yq`
- `fzf`（可选，交互选择）—— `brew install fzf`
- `jq`（JSON 处理，错题本）—— `brew install jq`

## 贡献

脚本按 `bash` 写，跨 macOS / Linux。如果有更优雅的实现（Python / Go），欢迎 PR。
